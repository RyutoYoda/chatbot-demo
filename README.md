# chatbot-demo

入力文をどう解釈したかを画面に出す、ルールベースのチャットボット。
ログイン不要・課金なしの静的ページ1枚（GitHub Pages）で動く。

**デモ:** https://ryutoyoda.github.io/chatbot-demo/

## これは何か

意図（intent）の照合を外部サービスに任せず、`正規化 → 照合 → しきい値判定` の3段で自分で実装している。
そのため「なぜその応答になったか」を画面の右側にそのまま出せる。

- 正規化後の文字列
- 採用した意図とスコア
- 当たり方（完全一致／部分一致／文字バイグラムの類似度）
- 一致した学習フレーズ
- 候補の上位3件とスコア、しきい値

## 構成

| ファイル | 役割 |
|---|---|
| `js/intents.js` | 意図の定義（学習フレーズと応答文）。ボット名の定数もここ |
| `js/nlu.js` | 正規化と照合。`classify(text)` が意図・スコア・根拠を返す |
| `js/app.js` | 画面の描画と、認識の内訳の表示 |
| `index.html` / `css/style.css` | 画面 |

ビルド工程も依存パッケージも無し。ES Modules をそのまま読み込んでいる。

## 照合の仕組み

1. **正規化** `normalize()` … NFKC・小文字化・カタカナ→ひらがな・記号と空白の除去。
   「コンニチハ！」「ｺﾝﾆﾁﾊ」「こんにちは。」が同じ文字列に寄る
2. **照合** `scoreAgainst()` … 学習フレーズごとにスコアを出す
   - 完全一致 → 1.0
   - 部分一致 → `0.55 + 0.4 × 長さ比`（短いほうが3文字未満のときは使わない）
   - それ以外 → 文字バイグラムの Dice 係数
3. **しきい値判定** … 最高スコアが `THRESHOLD`（0.42）未満なら `fallback` に落とす

## 既知の限界

- **否定が効かない。** 「さようならと言いたいけどまだ帰らない」が `goodbye`（0.66）になる。
  表層の文字の重なりしか見ていないため。
- **漢字とかなの差は正規化で吸収できない。** カタカナ→ひらがなは寄せられるが
  「名前」と「なまえ」は別物になるので、学習フレーズ側に両方を並べている。
- 学習フレーズを増やすほど部分一致の誤爆が増える。しきい値はフレーズ数と抱き合わせで調整が必要。
